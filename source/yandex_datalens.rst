Как загрузить данные на Яндекс DataLens
=======================================

* `Закажите данные <https://data.nextgis.com/ru/>`_ на интересующую Вас территорию в формате GeoJSON.
* Дождитесь получения результата, скачайте, распакуйте архив с данными.
* Выберите нужный слой, например муниципальное деление
* Используйте бесплатный конвертер "Подготовить векторный слой для DataLens" https://toolbox.nextgis.com/operation/vector2datalens чтобы сконвертировать слой в формат подходящий DataLens

В DataLens
* Создайте подключение, укажите сконвертированный файл
* Создайте датасет, укажите созданное подключение. В настройке полей укажите для первого поля тип Геополигон
* Создайте чарт. Выберите датасет, выберите тип чарт - карта, выберите поле типа Геополигон
